# Zeku for Scoop

[Zeku](https://zeku.dev) is a calm place to write for your Astro site: a native app that opens your project, knows your frontmatter schema, and publishes through your own git.

```powershell
scoop bucket add zeku https://github.com/davidvkimball/scoop-zeku
scoop install zeku/zeku
```

This installs the same signed installer you can download from [zeku.dev](https://zeku.dev/download), and it runs as a normal install, so Zeku keeps updating itself. Zeku is free for 14 days, then a one-time license from [zeku.dev/pricing](https://zeku.dev/pricing).

Remove it with `scoop uninstall zeku`.
